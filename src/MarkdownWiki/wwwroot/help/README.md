# Markdown 编辑速查（GFM）

本 Wiki 采用 **CommonMark + GitHub Flavored Markdown（GFM）** 作为书写规范，与 GitHub、多数静态文档站兼容。

在编辑页可打开右侧「语法帮助」，点击条目即可插入示例；也可访问完整帮助页：`/Help`。

## 图片约定

- 上传或 `Ctrl+V` 粘贴后，文件保存到当前文档同级的 `assets/` 目录  
- 正文插入相对路径：`![说明](assets/文件名.png)`  
- 阅读页通过 `/files/...` 提供静态访问  

## 推荐学习路径

1. 标题与段落  
2. 列表与链接  
3. 图片与代码块  
4. 表格与任务列表（GFM）
