# 预览演示示例（JSON / XML）

本目录用于验证资源管理器预览窗格与主程序「结构化预览」窗口。

## 文件一览

| 文件 | 用途 |
|------|------|
| `book-catalog.json` | 正常 JSON：嵌套对象 / 数组 |
| `app-settings.json` | 正常 JSON：配置风格 |
| `invalid.json` | **故意损坏**，应显示解析错误 |
| `library.xml` | 正常 XML：属性 + 子节点 |
| `config.xml` | 正常 XML：配置风格 |
| `invalid.xml` | **故意损坏**，应显示解析错误 |

## 方式 A：资源管理器预览窗格（推荐）

1. 运行主程序 → **资源管理器 → 启用预览窗格（.md/.json/.xml）**（同意 UAC）。
2. 打开资源管理器，启用「查看 → 预览窗格」（`Alt+P`）。
3. 进入本目录，依次点选上表文件。
4. 在预览工具栏切换：
   - **WinForms（更快更省）★** → 左侧树 + 右侧原文
   - **Web（还原度高）** → HTML 树 + 原文

## 方式 B：主程序内演示窗口

1. 运行主程序。
2. 菜单 **查看 → 预览演示…**，或 **文件 → 打开** 选择本目录下的 `.json` / `.xml`。
3. 可直接打开「打开 JSON 演示」「打开 XML 演示」。

## 预期结果

- 正常文件：树节点可展开，原文完整。
- `invalid.*`：不崩溃，显示可读的解析失败信息。
