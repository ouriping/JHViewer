# 快速开始

1. 准备一个包含多个 `.md` 的文档目录  
2. 在 `appsettings.json` 中配置 `Wiki:ContentRoot`  
3. 启动服务并用浏览器打开  
4. 点击阅读站「管理后台」，输入管理员密码（默认 `123456`）进入编辑主界面  
5. 在管理后台新建/编辑文档并保存  

## 编辑增强

- 阅读站与管理后台使用不同主界面；编辑需管理员登录  
- 工具栏可快速插入标题、列表、表格等 **GFM** 语法  
- **上传图片**，或在编辑区 `Ctrl+V` 粘贴剪贴板图片（自动保存到文档旁 `assets/` 并插入链接）  
- 右侧「语法帮助」可按标签筛选；完整说明见管理后台「编辑帮助」  

保存后刷新阅读页即可看到最新内容。
