# 长耗时 / 提权操作清单

主程序里哪些操作会卡住界面、需要进度条、超时取消或管理员权限。

## 分级

| 操作 | 典型耗时 | 进度条 | 超时/取消 | 管理员 | 现状 |
|------|----------|--------|-----------|--------|------|
| 启用预览窗格 | 数秒～数十秒 | 要（`PreviewRegistrationForm`） | 注册脚本要超时 | **可能**（UAC：Register / HKLM DisableLowIL） | 已有进度；脚本超时已缩短 |
| 取消预览窗格 | 同上 | 要 | 同上 | **可能** | 同上 |
| `RestartExplorer` | 失败时很长 | **要** | **要**（总超时约 8s） | 否 | **已改**：进度窗 + 超时 + 可取消等待 |
| `KillPrevhost` | 通常很快，卡死时慢 | 建议 | 单进程等待 ≤1.5s | 否 | **已改**：进度窗 + 短等待 |
| 预览诊断 | 一般很快 | 可选 | 可选 | 否 | **已改**：进度窗 |
| 注册/卸载右键菜单 | 瞬间 | 否 | 否 | 否（HKCU） | 保持同步即可 |
| 引擎切换 | 瞬间 | 否 | 否 | 否 | OK |
| 导出 HTML / CHM | 视文件 | 大目录建议 | CHM 编译已有等待上限 | 否 | CHM 已 `WaitForExit(120s)` |
| 检查更新（预览窗格） | 网络 | 否（链接文案） | Http/WebClient 超时 | 否 | 已有短超时 |

## `RestartExplorer` 原先为什么差

1. 在 UI 线程同步 `Kill` + `WaitForExit(5000)`，每个 explorer 最多卡 5 秒。  
2. 再 `Thread.Sleep(800)`，界面完全无反馈。  
3. 进程杀不掉时没有总超时，只能干等。  
4. 失败后也没有「用任务管理器拉起 explorer」的提示。

## 提权点（UAC）

| 步骤 | 原因 |
|------|------|
| `MarkdownPreview.Register.exe` + `runas` | 无提权 HKCU 注册失败时的回退 |
| `reg.exe` 写 `HKLM\...\DisableLowILProcessIsolation` | Win11 中等完整性 prevhost 需要 |

用户点「否」取消 UAC 时应尽快失败，不要再傻等满超时。当前提权进程等待上限约 12～30 秒，超时会 `Kill` 子进程。

## 不必加进度的

- 打开/保存 Markdown  
- 浏览记录读写  
- 复制路径、打开文件夹  
- 纯 HKCU 右键菜单注册
