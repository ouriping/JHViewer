# 构建与发布

## 本地构建

需要 Windows、.NET 8 SDK，以及 .NET Framework 4.8 目标包（预览处理程序和注册工具是 `net48`）。

```powershell
dotnet build .\src\MarkdownContextViewer.sln -c Release
dotnet test .\src\MarkdownWiki.Tests\MarkdownWiki.Tests.csproj -c Release --no-build
dotnet run --project .\src\MarkdownContextViewer\MarkdownContextViewer.csproj
```

主程序：

```powershell
dotnet run --project .\src\MarkdownContextViewer\MarkdownContextViewer.csproj -- --view .\samples\wiki-content\index.md
dotnet run --project .\src\MarkdownContextViewer\MarkdownContextViewer.csproj -- --register
```

## CI

`.github/workflows/ci.yml` 在 `windows-latest` 上构建 `src/MarkdownContextViewer.sln`（Release），并运行 MarkdownWiki 单元测试。推送到 `master` 和指向 `master` 的拉取请求都会触发。

## 发布包

`.github/workflows/release.yml` 在推送 `v*.*.*` 标签时：

1. 在 `windows-latest` 上 `dotnet publish` 主程序，运行时 `win-x64`，自包含。
2. 把已编译的预览处理程序和 `MarkdownPreview.Register.exe` 复制到发布目录的 `preview-handler\`（不要放在根目录，否则 net48 的 `System.Memory` 4.x 会覆盖 .NET 8 的 8.0.0.0）。
3. 检查根目录 `System.Memory.dll` 的程序集版本是 8.0.0.0，然后打成 `JHViewer-<标签>-win-x64.zip`。
4. 创建或更新同名 GitHub Release，并附上该 zip。

本地打出同样的目录：

```powershell
dotnet build .\src\MarkdownContextViewer.sln -c Release
dotnet publish .\src\MarkdownContextViewer\MarkdownContextViewer.csproj -c Release -r win-x64 --self-contained true -p:BuildProjectReferences=false -p:DebugType=None -p:DebugSymbols=false -o .\artifacts\publish
```

推送标签（示例）：

```powershell
git tag v0.1.2
git push origin v0.1.2
```

发布页：<https://github.com/ouriping/JHViewer/releases>

资产文件名形如 `JHViewer-v0.1.2-win-x64.zip`。下载链接形如：

`https://github.com/ouriping/JHViewer/releases/download/v0.1.2/JHViewer-v0.1.2-win-x64.zip`

主程序不需要单独安装 .NET 8。预览窗格仍依赖系统里的 .NET Framework 4.8 和 WebView2 运行时。
