JHViewer 0.1.1
许可证：木兰宽松许可证，第 2 版（MulanPSL-2.0）。见仓库 LICENSE。

可执行文件名仍是 MarkdownContextViewer.exe（与预览组件、注册表兼容）。产品名是 JHViewer。
v0.1.0 的压缩包会在打开时立刻退出，请使用 v0.1.1。

1. 解压后直接运行 MarkdownContextViewer.exe，打开主界面（编辑、导出、Wiki、预览窗格设置）。
2. 注册资源管理器集成（当前用户，不必管理员）：
   - 主界面菜单「资源管理器 → 注册默认打开与右键菜单」
   - 或命令：MarkdownContextViewer.exe --register
   取消注册：MarkdownContextViewer.exe --unregister
3. 注册之后，在资源管理器中双击或右键打开 .md、.markdown、.json、.xml，
   只会打开单文件查看窗口，不会打开主界面。
   也可以手动执行：MarkdownContextViewer.exe --view 文件路径
4. 预览窗格里的「编辑」会打开主界面（参数 --edit）。
5. 资源管理器预览窗格需要系统自带的 .NET Framework 4.8，以及 Microsoft Edge WebView2 运行时。
   主程序本身是自包含的 win-x64 构建，不需要单独安装 .NET 8。
