# 单文件打开（不进入主界面）

从资源管理器打开 `.md`、`.markdown`、`.json`、`.xml` 时，JHViewer 只显示该文件的查看窗口，不创建主界面 `FrmMain`（没有历史列表、发布中心或完整菜单）。

## 启动规则

| 启动方式 | 结果 |
| --- | --- |
| 直接运行 `MarkdownContextViewer.exe` | 主界面 |
| 双击已关联的文档，或右键「打开」/「用 JHViewer 打开」 | 单文件查看窗口 |
| `MarkdownContextViewer.exe --view 文件` | 单文件查看窗口 |
| `MarkdownContextViewer.exe 文件.md`（扩展名是受支持文档） | 单文件查看窗口 |
| `MarkdownContextViewer.exe --edit 文件.md` | 主界面，并在其中打开该文件 |
| `MarkdownContextViewer.exe --register` | 为当前用户注册关联，不打开主界面 |
| `MarkdownContextViewer.exe --unregister` | 取消当前用户的关联 |

`--edit` 优先于 `--view`。预览窗格里的「编辑」会传 `--edit`，因此仍进入主界面。文件关联写入的命令是：

```text
"MarkdownContextViewer.exe" --view "%1"
```

关联范围：`.md`、`.markdown`、`.json`、`.xml`。`.mdown` 不注册为默认打开，但如果把路径传给程序，也会按 Markdown 单文件窗口打开。

图标在 `src/MarkdownContextViewer/Assets/Icons/`（`jhviewer-md.ico`、`jhviewer-json.ico`、`jhviewer-xml.ico`），发布后位于程序目录的 `icons\`。注册时写入各 ProgId 的 `DefaultIcon`：

| 扩展名 | 图标 |
| --- | --- |
| `.md`、`.markdown` | `icons\jhviewer-md.ico` |
| `.json` | `icons\jhviewer-json.ico` |
| `.xml` | `icons\jhviewer-xml.ico` |

三种图是同一张文档版式（折角、正文横线和底部徽章），徽章颜色和文字不同。找不到 ico 时才回退到主程序图标。`--unregister` 会删掉这些 ProgId。已经注册过的用户，下次打开主界面会把 `DefaultIcon` 更新到上述路径。

## 窗口内容

- Markdown（`.md` / `.markdown` / `.mdown`）：复用 `MarkdownPreview.Shell` 的 `MarkdownPreviewForm`，只渲染当前文件。
- JSON / XML：复用主程序里的结构化预览（树 + 原文），并隐藏「JSON 演示」「示例目录」等入口。

单文件进程使用自己的 Mutex / 命名管道（`Local\JHViewer.SingleFileViewer`）。它不会把路径转给已经打开的主界面。同一文件再次打开时，会激活已有窗口。

主界面仍使用原来的单实例通道。只有 `--edit` 或不带文档路径的启动会进入该通道。

## 注册

注册写入当前用户（HKCU），包含：

- ProgId `MarkdownContextViewer.md`、`.markdown`、`.json`、`.xml` 的 `shell\open\command`
- 「打开方式」
- `SystemFileAssociations\<扩展名>\shell\MarkdownContextViewer` 右键动词，显示为「用 JHViewer 打开」

若以前已经注册过，主界面启动时会尝试把旧的 `"exe" "%1"` 命令升级为 `--view`，并在 `.md` 仍由本程序接管时补上 `.markdown`。从未注册过的机器不会被自动占用默认应用。

手动注册一次即可覆盖升级：

```text
MarkdownContextViewer.exe --register
```

## 和预览窗格的区别

资源管理器预览窗格仍由 `MarkdownPreview.Handler`（.NET Framework 4.8 + SharpShell）负责，选中文件时在窗格里预览，不启动主程序。这是另一条路径，本次没有改掉它的 COM 注册方式。
