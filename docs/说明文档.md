# JHViewer 代码结构说明

产品名是 **JHViewer**。解决方案、项目和可执行文件仍叫 `MarkdownContextViewer`，以便预览处理程序和已有注册表项继续工作。

- 直接运行 `MarkdownContextViewer.exe`：打开主界面。
- 资源管理器打开 `.md` / `.markdown` / `.json` / `.xml`，或命令行 `--view 文件`：只打开单文件查看窗口，不创建主界面。详见 [`单文件打开.md`](单文件打开.md)。

## 一、目录布局

```
MarkdownContextViewer/
├── MarkdownContextViewer.sln
├── docs/
│   ├── 说明文档.md
│   ├── 预览窗格.md
│   └── 网站访问功能设计说明.md
└── src/
    ├── MarkdownContextViewer/       # 主程序 net8.0-windows
    │   ├── UI/                      # 窗体、控件
    │   ├── Services/                # 业务服务
    │   └── Program.cs
    ├── MarkdownPreview.Handler/     # Explorer 预览：SharpShell + WebView2 (net48)
    ├── MarkdownPreview.Register/    # COM 注册工具 (net48)
    └── MarkdownPreview.Shell/       # 应用内调试预览窗体 (net8)
```

## 二、职责划分

### 主程序 `MarkdownContextViewer`

| 目录 | 内容 |
|------|------|
| `UI/` | `FrmMain`、`PublishCenterForm`、`MarkdownEditorControl` |
| `Services/` | 历史、渲染、导出、本地站点、Explorer 集成 |

- `Program.cs`：入口。无参数进入主界面；`--view` 或文档路径进入单文件查看；`--edit` 把文件交给主界面（预览窗格里的「编辑」使用这个参数）。
- `FrmMain`：UI 协调层，调用 Services，不直接写注册表/JSON 细节。

### 预览相关

| 项目 | 职责 |
|------|------|
| `MarkdownPreview.Handler` | 资源管理器预览窗格 COM（SharpShell + Markdig + WebView2） |
| `MarkdownPreview.Register` | `install` / `uninstall` 注册工具 |
| `MarkdownPreview.Shell` | 主程序内「Markdown 预览」调试窗体（非 Explorer） |

## 三、核心流程

1. **打开/保存 Markdown**：`FrmMain` → `MarkdownEditorControl` → `MarkdownRenderService`
2. **右键菜单**：`ExplorerIntegrationService.RegisterContextMenu` / `UnregisterContextMenu`（HKCU）
3. **Explorer 预览开关**：部署 Handler → `MarkdownPreview.Register.exe` → 关联 `.md` → 结束 `prevhost`

## 四、运行

```powershell
dotnet build .\MarkdownContextViewer.sln
dotnet run --project .\src\MarkdownContextViewer\MarkdownContextViewer.csproj
```

预览窗格：查看 → 预览窗格（Alt+P），选中 `.md`。需已安装 WebView2 Runtime。
